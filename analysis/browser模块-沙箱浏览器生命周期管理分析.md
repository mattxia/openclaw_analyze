# browser.ts 沙箱浏览器管理模块分析

## 文件概述

`browser.ts` 是沙箱浏览器管理的核心模块，负责在 Docker 容器中创建、管理和维护浏览器实例。通过 CDP (Chrome DevTools Protocol) 与浏览器通信，提供浏览器自动化能力。

**文件路径**: `src/agents/sandbox/browser.ts`

---

## 关键函数说明

### waitForSandboxCdp()

```
waitForSandboxCdp({ cdpPort, timeoutMs })
       │
       ▼
┌─────────────────────────────────────────────────────────────┐
│ 轮询检测 CDP 就绪                                            │
│                                                             │
│ while (Date.now() < deadline) {                             │
│   fetch("http://127.0.0.1:{cdpPort}/json/version")          │
│   │                                                         │
│   ├── 成功 (res.ok) → return true                          │
│   └── 失败 → 等待 150ms 后重试                              │
│ }                                                           │
│                                                             │
│ 超时 → return false                                        │
└─────────────────────────────────────────────────────────────┘
```

**用途**: 等待容器内的 Chromium 启动完成并开始监听 CDP 端口

**参数**:
- `cdpPort`: CDP 端口号
- `timeoutMs`: 超时时间（毫秒）

**返回值**: `boolean` - 是否在超时前检测到 CDP 就绪

### 热浏览器机制

```
热浏览器判断逻辑
       │
       ▼
┌─────────────────────────────────────────────────────────────┐
│ 条件: running && (lastUsedAtMs 不存在 || now - lastUsedAtMs < 5min) │
│                                                             │
│ 结果:                                                     │
│ ├── 热浏览器 → 仅记录警告，不重建                            │
│ └── 冷浏览器 → 删除旧容器，重建新容器                        │
└─────────────────────────────────────────────────────────────┘
```

**目的**: 避免频繁重建正在使用的浏览器，提升响应速度

## 安全机制

| 机制 | 说明 |
|------|------|
| 配置哈希 | 检测配置变更，决定是否重建容器 |
| 热浏览器保护 | 5 分钟内使用的浏览器不会被重建 |
| 认证隔离 | 每个沙箱有独立的认证令牌 |
| 网络隔离 | 支持自定义 Docker 网络模式 |
| CDP 源范围 | 可选限制 CDP 访问来源 IP |
| NoSandbox 标志 | Chromium 在容器内不需要 setuid 沙箱 |
| 端口绑定 | 只绑定到 127.0.0.1，不对外暴露 |

## 常量配置

| 常量 | 值 | 说明 |
|------|-----|------|
| `HOT_BROWSER_WINDOW_MS` | 5 * 60 * 1000 (5分钟) | 热浏览器窗口时间 |
| `CDP_SOURCE_RANGE_ENV_KEY` | "OPENCLAW_BROWSER_CDP_SOURCE_RANGE" | CDP 源范围环境变量 |
| `DEFAULT_SANDBOX_BROWSER_IMAGE` | (见 constants.ts) | 默认浏览器镜像 |

